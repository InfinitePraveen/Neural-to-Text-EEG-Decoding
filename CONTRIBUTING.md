# Contributing

Thanks for considering a contribution.

## Guidelines
- Keep the project CPU-friendly and avoid unnecessary large downloads.
- Prefer clear, notebook-first experiments over additional framework layers.
- Never commit private, identifiable, or restricted EEG recordings.
- Document dataset provenance, license, participant split, sampling rate, channels, and preprocessing.
- Do not report synthetic-demo metrics as real EEG results.
- Keep model claims proportional to the evidence.

## Suggested workflow
1. Fork the repository and create a focused feature branch.
2. Install dependencies from `requirements.txt`.
3. Run the notebook from top to bottom.
4. Include a short description of the experiment and its limitations in your pull request.
